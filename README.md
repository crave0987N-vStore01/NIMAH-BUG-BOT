# NIMAH BUG BOT PRO

A customized multi-device WhatsApp bot project with a red-and-black pairing website theme.

## Run the bot
1. Install a supported Node.js LTS release.
2. Open `NIMAH BUG BOT PRO/` and run `npm install`.
3. Run `npm start`.

## Website
Open `NIMAH BUG BOT PRO Web/`. Install dependencies with `npm install` and use the hosting provider’s Node.js start command for the API. Configure secrets as environment variables; do not commit credentials or session files.
